## 🌱 O projekcie

Projekt **Ziemia 2076** ma na celu przybliżenie możliwego wyglądu świata za 50 lat. Przedstawia prognozowane zmiany środowiskowe na podstawie obserwowanych trendów i dostępnej wiedzy o zmianach klimatu.

Strona pozwala spojrzeć w przyszłość i zastanowić się, jak obecne decyzje ludzi mogą wpłynąć na stan naszej planety.

## ✨ Funkcjonalności

- 🌡️ Prezentacja przewidywanych zmian klimatycznych.
- 📊 Zestawienie wartości bazowych z prognozami na 2076 rok.
- 🌍 Przedstawienie potencjalnych zmian zachodzących na Ziemi.
- 🖥️ Interfejs strony internetowej z wykorzystaniem HTML i CSS.
- 🐍 Obsługa aplikacji internetowej za pomocą frameworka Flask.

## 🛠️ Wykorzystane technologie

## 🚀 Uruchomienie projektu

### Wymagania

- Python 3.10 lub nowszy
- pip – menedżer pakietów Pythona
- Git (opcjonalnie)

### 1. Pobranie repozytorium

```bash
git clone https://github.com/michal6769/Ziemia-2076.git
cd Ziemia-2076
```

### 2. Utworzenie środowiska wirtualnego

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

Linux / macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Instalacja Flask

```bash
pip install flask
```

Jeżeli projekt zawiera plik `requirements.txt`, zainstaluj zależności za pomocą:

```bash
pip install -r requirements.txt
```

### 4. Uruchomienie aplikacji

```bash
python main.py
```

Następnie otwórz przeglądarkę i przejdź pod adres:

**http://127.0.0.1:5000**

## 📈 Informacje o prognozach

Wartości przedstawione na stronie dotyczą przewidywanego stanu świata w 2076 roku. Należy traktować je jako szacunki i możliwe scenariusze, a nie jako pewne przewidywania przyszłości.

Rzeczywiste zmiany będą zależeć między innymi od emisji gazów cieplarnianych, rozwoju technologii, polityki klimatycznej i działań podejmowanych przez społeczeństwa.

## 🎯 Cel projektu

Celem projektu jest zwiększanie świadomości ekologicznej oraz pokazanie, jak istotne są działania podejmowane obecnie w kontekście przyszłości Ziemi.

Projekt ma również charakter edukacyjny i służy rozwijaniu umiejętności tworzenia stron internetowych z wykorzystaniem Pythona, Flask, HTML i CSS.
